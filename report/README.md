# Research reports

- [`EXECUTIVE_SUMMARY.md`](EXECUTIVE_SUMMARY.md) gives the short version of the question, setup and conclusions.
- [`FULL_REPORT.md`](FULL_REPORT.md) contains the complete methods, experimental sequence, interpretation and limitations.
- [`FALSIFICATION_REPORT.md`](FALSIFICATION_REPORT.md) preserves the chronological record of follow-up experiments and changing conclusions.
- [`MULTIDIMENSIONAL_RESULTS.md`](MULTIDIMENSIONAL_RESULTS.md) records the subspace and intrinsic-rank follow-up.
- [`FINDINGS.md`](FINDINGS.md) contains the superseded pilot interpretation.

Figures used by the reports are stored in `report_assets/`.
