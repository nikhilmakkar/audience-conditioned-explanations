# Stimulus sets

- `stimuli.json` — initial pilot stimuli
- `stimuli_matched.json` — matched expert-versus-expert design
- `stimuli_domain_matched.json` — domain-matched discovery set
- `stimuli_domain_matched_8.json` — eight-domain discovery set used for the main direction
- `stimuli_prospective_synthetic.json` — eight invented methods used for prospective testing
- `stimuli_prospective_profile_paraphrase.json` — rewritten reader profiles used for the wording control

The prospective methods are synthetic. Their passages and candidate summaries received light human review, as discussed in the report limitations.
